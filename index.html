A lightweight monitoring daemon written in C that reads CPU temperature, RAM usage, and system load directly from the Linux kernel via /proc/ and /sys/. Logs every metric to a local SQLite database, fires real-time alerts via webhook, and automatically shuts down if temperature exceeds a critical threshold. Zero external dependencies.
