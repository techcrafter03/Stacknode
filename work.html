Live Security Monitoring / C / Bash / SQLite
iPaaS Edge Monitoring Hub

A Linux security and health monitoring agent written in C and Bash. Ten checks watch for SSH brute-force attempts, unauthorized key changes, log tampering, privilege escalation, and more, each tested against real attack tools. Every result is logged to SQLite for a full audit trail, alerts go to Discord and Slack, and a built-in dashboard shows live status. One setup script installs it in under 10 minutes.

  • +Ten attack-tested detection checks: SSH brute-force, key changes, log tampering, privilege escalation, firewall state, and more
  • +Full audit trail: every check, every run, logged to SQLite with timestamps
  • +Webhook alerts to Discord and Slack, both live and tested
  • +Built-in static dashboard with live status, no external monitoring platform needed
  • +Deployed in under 10 minutes, runs from a systemd timer every 5 minutes
