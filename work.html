Live Monitoring / C / Bash / SQLite
iPaaS Edge Monitoring Hub

A Linux monitoring agent written in C. It reads CPU temperature, RAM and load straight from the kernel, logs every metric to SQLite, alerts your team by webhook, and can shut a machine down before heat damages it. The C engine needs no external libraries, and Bash, curl and SQLite handle the rest. One setup script installs it.

  • +Reads /proc and /sys through POSIX calls, no agent framework
  • +Full audit trail: every metric and alert stored with a timestamp
  • +Webhook alerts (Discord live; Slack and Teams in development)
  • +Optional protective shutdown at a critical temperature
  • +Deployed in under 10 minutes, runs from a systemd timer every 5 minutes
